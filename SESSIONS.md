# Training Sessions (4 weeks, 2 sessions a week, about 90 minutes each)
Each session = 15 min recap/demo, 45 min hands-on, 20 min review, 10 min Q&A. Trainer demonstrates live, learners type everything.

| Week | Session | Topic | Modules |
|---|---|---|---|
| 1 | 1 | Terminal basics: `ls cd pwd mkdir cp mv rm cat less`, permissions (`chmod`) | warm-up |
| 1 | 2 | First script, variables, input | 01, 02 |
| 2 | 3 | if/else, exit codes | 03 |
| 2 | 4 | Loops and counting | 04 |
| 3 | 5 | Functions and arguments | 05 |
| 3 | 6 | grep/cut/sort/awk/sed, pipes | 06 |
| 4 | 7 | case, arrays, safe scripts | 07, 08 |
| 4 | 8 | Logging, cron, mini project, project demos | 09, 10, projects |

**Trainer tips:** run `bash -x` on a broken script live; let learners predict output before running; end each session with one "make it yours" challenge.
**Self-study:** do one session per day; time-box yourself; always complete the module check before moving on.
