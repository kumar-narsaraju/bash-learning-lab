# Contributing
- New module: copy an existing folder in `modules/`, change `lesson.md`, `input.txt`, `expected.txt`, `solution.sh` (and `args.txt` if needed).
- `./check-all.sh --solution` must pass before you open a pull request.
- Keep explanations short, with one concept per module. Use `shellcheck` on every script.
- Community projects go in `community/<your-name>/`.
