# Module 10: Mini Project: Word Report

## Learn
Combine everything. Plan first (input, steps, output), then code in small pieces, testing as you go.
Tips: `${#word}` is a string's length; `while read -r line` reads input line by line.

## Your turn
Read words, one per line. Print `Count: N` and `Longest: WORD` (the first longest).

Create `answer.sh` in this folder, then check from the repo root:
```bash
./check.sh 10
```
Stuck? Re-read the lesson, run your script by hand, and only then look at `solution.sh`.
